OKF Skills

AIコーディングエージェントに、
「プロジェクトの知識」と「仕事のやり方」を渡すためのテンプレート集です。

そもそも OKF って何？

OKF（Open Knowledge Format）は、プロジェクトについてAIに覚えておいてほしい情報を、 Markdownで整理して置いておくための形式です。

たとえば：
  • このシステムはどういう構成なのか
  • どんな機能があるのか
  • データはどういう形なのか
  • 開発時に守るルールは何か

つまり、AI向けの「プロジェクトの共有ノート」みたいなものです。

Skill は何？

Skillは、AIに「どう作業してほしいか」を伝える手順書です。

このリポジトリには、たとえばこんな Skill があります。
  • implement-feature — 機能を追加するとき
  • investigate-bug — バグを調べるとき
  • add-test — テストを追加するとき
  • refactor-safely — 挙動を変えずに整理するとき
  • update-okf — 変更後にOKFを更新するとき

OKF と Skill の違い

OKF
「このプロジェクトでは何が正しい？」
＋
Skill
「この作業はどう進める？」
↓
Codex / Claude Code
プロジェクトを理解したうえで作業する

この2つを分けることで、巨大なプロンプトを毎回書かなくても、 AIが必要な知識と手順を再利用しやすくなります。

このリポジトリは何をしてくれる？

okf-skills は、OKFとSkillを自分のリポジトリへ導入しやすくするためのスターターキットです。

  • OKFのひな形
  • よく使う開発Skill
  • Codex向けの AGENTS.md
  • Claude Code向けの CLAUDE.md
  • そのまま参考にできるサンプル構成

使い方はシンプル

  1. 必要なファイルを自分のリポジトリへコピーする
  2. okf/ に自分のプロジェクト情報を書く
  3. CodexやClaude CodeにSkillを使って作業させる
  4. 仕様が変わったらOKFも更新する
一言でいうと：

OKF Skills は、AIに毎回ゼロから説明しなくていい開発環境を作るためのテンプレートです。
